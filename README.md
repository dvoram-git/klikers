# קליקרים – מערכת אירוע עם IVR

מיזם זה כולל:
- שרת Node.js + Express + Socket.io
- מסך הקרנה בזמן אמת
- לוח ניהול למנחה
- קבלת תשובות דרך IVR / ימות המשיח דרך webhook
- לוח תוצאות דינמי עם ניקוד לפי ריבוי תשובות נכונות ומהירות

## מבנה הקבצים

- `server.js` – השרת הראשי של היישום
- `public/index.html` – ממשק לוח ההקרנה ולוח הניהול
- `public/styles.css` – עיצוב UI
- `public/app.js` – קוד ה-frontend והחיבור ל-Socket.io

## התקנה

1. פתח את התיקייה בפרויקט
2. הרץ:

```bash
npm install
```

3. כדי להפעיל את השרת:

```bash
npm start
```

השרת יופעל על:

```text
http://localhost:3000
```

## שימוש

### מסך הקרנה
פתח את הדפדפן בכתובת:

```text
http://localhost:3000
```

שם תראה את מסך ההקרנה וממשק הניהול בצד שמאל.

### שליטה במשחק
במסך הניהול אפשר:
- להתחיל את המשחק
- לעבור לשאלה הבאה
- להציג את התשובה הנכונה
- לאפס את המשחק

## Webhook ל-IVR / ימות המשיח

השרת מקבל התשובות מאתר ה-IVR דרך endpoint:

```text
POST http://localhost:3000/api/ivr/callback
```

### דוגמת payload

```json
{
  "phone": "972501234567",
  "digit": 3
}
```

או:

```json
{
  "callerId": "972501234567",
  "digit": 2
}
```

השרת מחפש את הספרה 1-4, מאמת שהשאלה פעילה, מעדכן את ניקוד המשתתף ומעביר עדכון מיידי דרך Socket.io למסך ההקרנה.

### לוגיקה של ניקוד
- תשובה נכונה: +10 נקודות
- בונוס מהירות: נוסף על פי הזמן שנותר לשאלה
- תשובה שגויה: לא מוסיפים נקודות

## דוגמת קריאת webhook דרך curl

```bash
curl -X POST http://localhost:3000/api/ivr/callback \
  -H "Content-Type: application/json" \
  -d '{"phone":"972501234567","digit":1}'
```

## התאמה למערכת IVR

במערכת ה-IVR / ימות המשיח, בקש ממנה לשלוח POST לכתובת ה-Webhook בכל פעם שהמשתתף מקיש ספרה. ההערך `digit` צריך להיות בין 1 ל-4, ותמיד יישלח יחד עם מספר הטלפון של המתקשר.
